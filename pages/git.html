wprowadzenie

Praca z repozytorium

Git zapisuje historię zmian w projekcie i pozwala bezpiecznie pracować na osobnych branchach. GitHub służy do przechowywania repozytorium oraz współpracy przez Pull Requesty.

Dobra praktyka: przed rozpoczęciem pracy sprawdź status repozytorium i pobierz aktualny main.

Podstawowe polecenia Git
Polecenie Przykład użycia Znaczenie
git clonegit clone URLPobiera zdalne repozytorium i tworzy lokalny katalog projektu.
git statusgit statusPokazuje gałąź oraz zmienione, nieśledzone i przygotowane pliki.

procedura

Typowy przebieg pracy

  1. Zsynchronizuj lokalny main poleceniem git pull --ff-only origin main.
  2. Utwórz osobny branch dla zmiany, na przykład feature/html-git.
  3. Wprowadź zmianę i sprawdź ją poleceniem git status.
  4. Dodaj pliki, utwórz commit i wypchnij branch na GitHub.
  5. Otwórz Pull Request, poproś o review i po poprawkach scal zmianę z main.
